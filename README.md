# ZELA — Sprint 2 | Web Development

## Sobre o ZELA

O ZELA é um projeto que estamos desenvolvendo na FIAP, pensando em como a tecnologia pode ajudar a população a se preparar e agir em situações de risco, como enchentes, alagamentos e deslizamentos.

Nesta Sprint 2, reunimos o trabalho das disciplinas de Web Development e Front-End Design em um único protótipo, utilizando HTML, CSS e JavaScript. O site possui cinco páginas e três fluxos de navegação, com funcionalidades demonstrativas para moradores e para a Defesa Civil.

## O que desenvolvemos?

**Página Início**

- Exibição de um alerta de risco demonstrativo.
- Acesso às três funcionalidades principais do ZELA.
- Navegação entre as páginas pelo menu superior.

**Consulta de Locais Seguros — Fluxo 1**

- Preenchimento do endereço e seleção entre dois abrigos.
- Validação dos campos e exibição de mensagens de erro.
- Exibição do mapa demonstrativo conforme o abrigo escolhido.
- Atualização das informações sem recarregar a página.

**Registro de Ocorrência — Fluxo 2**

- Formulário para registrar situações de risco.
- Seleção do tipo de ocorrência, endereço, descrição e foto opcional.
- Validação dos campos obrigatórios.
- Exibição de uma página de confirmação após o preenchimento correto.

**Painel da Defesa Civil — Fluxo 3**

- Seleção da região monitorada.
- Alteração do nível de risco (baixo, moderado ou alto).
- Atualização das mensagens e cores dos alertas.
- Visualização de ocorrências demonstrativas.
- Opção de marcar ocorrências como verificadas ou desfazer a verificação.

## Como visualizar o projeto

Basta baixar o repositório e abrir o arquivo `index.html` no navegador.

Pela página Início ou pelo menu superior, é possível acessar as três funcionalidades principais:

- **Locais Seguros:** consultar os abrigos e visualizar os mapas demonstrativos.
- **Registrar ocorrência:** preencher o formulário e acessar a página de confirmação.
- **Defesa Civil:** gerenciar os níveis de risco e verificar ocorrências.

O projeto funciona diretamente no navegador, sem necessidade de instalar programas adicionais.

## Importante

O ZELA ainda é um protótipo acadêmico. Os mapas, abrigos, alertas e ocorrências são demonstrativos e não representam informações reais de segurança.

As rotas são ilustrativas e não são calculadas a partir do endereço informado. O formulário de ocorrência também é uma simulação, sem envio de dados para a Defesa Civil.

As funcionalidades trabalham com dados pré-definidos, sem conexão com banco de dados ou atualização automática entre as páginas.
